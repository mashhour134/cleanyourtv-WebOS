# شاشة سَكينة: مواقيت الصلاة والأذكار

## الهدف

إضافة شاشة توقف اختيارية إلى CleanYourTV تجمع مواقيت الصلاة والأذكار والصوت، وتبقى قابلة للاستخدام بالريموت. تستفيد من حماية OLED الحالية وتعمل دون إزعاج المشاهدة.

## تجربة المستخدم

- تبدأ يدويًا من الشاشة الرئيسية أو تلقائيًا بعد مدة خمول يحددها المستخدم.
- تعرض الصلاة القادمة واسمها والعد التنازلي، مع مواقيت اليوم.
- تعرض ذكرًا واحدًا في كل مرة، مع النص كاملًا وعدد التكرار والمصدر.
- يفتح OK تفاصيل الذكر أو يزيد العداد؛ الأسهم تتنقل بين الأذكار؛ Back يغلق الشاشة.
- لا يبدأ أي صوت افتراضيًا. يمكن للمستخدم اختيار الأذان أو تلاوة الأذكار، مستوى الصوت، والصلوات التي يصدر عندها التنبيه.
- أي ضغطة ريموت توقف الصوت وتعيد المستخدم مباشرة إلى الشاشة الرئيسية.

## الإعدادات

1. المدينة أو إحداثيات الموقع.
2. طريقة حساب المواقيت، مع ضبط يدوي بالدقائق لكل صلاة.
3. مدة الخمول قبل تشغيل الشاشة.
4. تشغيل الأذان أو التلاوة، الصوت، والتنبيه لكل صلاة.
5. تشغيل الشاشة يدويًا أو تلقائيًا، وخيار إيقاف الصوت أثناء تشغيل تطبيق آخر.

يُحسب الوقت وفق إعداد المستخدم، وتُعرض الطريقة والمدينة بوضوح. المواقيت الحسابية قد تختلف عن المسجد المحلي؛ لذلك يجب توفير التعديل اليدوي وعدم تقديمها كبديل عن التقويم المحلي المعتمد.

## التصميم وحماية OLED

- خلفية سوداء أو داكنة جدًا، ونص عربي كبير ومقروء من الأريكة.
- تخفيض السطوع بعد فترة، وتحريك عناصر الواجهة تدريجيًا.
- تغيير الذكر أو ترتيب المعلومات دوريًا لتجنب بقاء عناصر عالية التباين ثابتة.
- عدم استخدام صور ساطعة أو مؤثرات مستمرة أو حركة ثقيلة على معالج التلفزيون.

## المحتوى والصوت

- تخزين الأذكار ومراجعها محليًا ليعمل العرض دون إنترنت.
- تضمين نصوص موثقة مع المصدر وعدد التكرار، وعدم إضافة نص غير موثق.
- ملفات الصوت اختيارية وقابلة للإيقاف؛ لا تُرسل بيانات الموقع أو الصوت إلى خدمة خارجية دون موافقة صريحة.

## مراحل التنفيذ

1. بطاقة مواقيت الصلاة والذكر اليومي داخل نظام البطاقات الحالي.
2. شاشة توقف كاملة مع تنقل الريموت وحماية OLED.
3. إعداد المدينة وطريقة الحساب والتنبيهات.
4. تشغيل الصوت اختياريًا، ثم اختبار التوافق على إصدارات webOS المدعومة.

## معايير القبول

- يمكن إعداد الميزة وإيقافها بالكامل من الريموت.
- لا تحجب الشاشة الرئيسية أو تمنع الخروج بزر Back.
- لا يعمل الصوت دون تفعيل صريح.
- تبقى الأذكار متاحة دون اتصال.
- تعرض المواقيت المدينة وطريقة الحساب والتعديلات بوضوح.
